# 商品分类图片说明

此目录用于存放商品分类的缩略图（JPG 格式）。

## 需要的图片文件

请将以下图片文件放置在此目录中：

1. **mousepad.jpg** - 鼠标垫分类图片
2. **tapestry.jpg** - 挂毯分类图片
3. **business-card.jpg** - 名片分类图片
4. **greeting-card.jpg** - 贺卡分类图片
5. **tshirt.jpg** - T恤分类图片
6. **hoodie.jpg** - 卫衣分类图片
7. **tote-bag.jpg** - 帆布袋分类图片
8. **poster.jpg** - 海报分类图片
9. **postcard.jpg** - 明信片分类图片
10. **sticker.jpg** - 贴纸分类图片

## 图片要求

- **格式**: JPG
- **尺寸**: 建议 200x200 像素或更高（正方形）
- **大小**: 建议每个文件不超过 100KB
- **风格**: 统一风格，清晰展示商品类型特征

## 使用方式

图片路径会自动映射到 `/product-categories/[文件名].jpg`，在商品类型选择器和表格中显示。

如果图片文件不存在，图片将不会显示（已添加错误处理）。
