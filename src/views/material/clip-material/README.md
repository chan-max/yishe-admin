# 文件素材管理模块

## 功能概述

文件素材管理模块是一个用于管理各种文件素材的前端模块，支持上传、编辑、预览、下载和删除功能。该模块与后端API紧密集成，提供完整的文件素材管理解决方案。

## 主要功能

### 1. 文件列表展示
- 支持分页显示文件素材列表
- 提供多种筛选条件：关键词搜索、排序、文件格式、分类、ID、时间范围
- 支持多选操作
- 实时显示文件预览（视频文件可播放，其他文件显示对应图标）

### 2. 文件上传
- 支持上传任意格式的文件
- 文件大小限制：最大1GB
- 支持批量上传
- 实时显示上传进度和状态
- 自动上传到腾讯云COS存储
- 支持设置文件名称、描述、关键词、分类、标签等元数据

### 3. 文件编辑
- 支持修改文件的基本信息（名称、描述、关键词、分类、标签）
- 文件本身不可修改，只能修改文字内容
- 实时保存到后端数据库

### 4. 文件预览/下载
- 视频文件支持在线预览播放
- 所有文件支持下载功能
- 支持批量下载
- 文件名自动生成（格式：file_文件名.扩展名）

### 5. 文件删除
- 支持单个文件删除
- 支持批量删除
- 删除确认提示
- 同时删除COS存储中的文件

## 数据库字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | string | 主键ID |
| url | string | 文件URL地址 |
| name | string | 文件名称 |
| description | string | 文件描述 |
| keywords | string | 关键词（逗号分隔） |
| suffix | string | 文件扩展名 |
| category | string | 分类 |
| tags | string | 标签（逗号分隔） |
| userId | string | 归属用户ID |
| isPublic | boolean | 是否公开 |
| isDeleted | boolean | 是否删除 |
| createTime | Date | 创建时间 |
| updateTime | Date | 更新时间 |

## 分类选项

- 风景
- 人物
- 动物
- 建筑
- 动画
- 其他

## 支持的文件格式

### 视频文件
- mp4, mov, avi, mkv, wmv, flv, webm, m4v, 3gp, ogv

### 图片文件
- jpg, jpeg, png, gif, bmp, webp, svg, ico, tiff, tif

### 文档文件
- pdf, doc, docx, xls, xlsx, ppt, pptx, txt, rtf

### 其他文件
- 支持任意格式的文件上传

## 使用说明

### 1. 查看文件列表
1. 进入"设计资源" -> "剪辑素材"页面
2. 使用搜索框和筛选条件查找文件
3. 点击文件预览查看详情

### 2. 上传文件
1. 点击"上传"按钮
2. 选择要上传的文件（支持任意格式）
3. 填写文件信息（名称、描述、关键词、分类、标签）
4. 点击"上传"按钮开始上传
5. 等待上传完成

### 3. 编辑文件
1. 在文件列表中点击"编辑"按钮
2. 修改文件的基本信息
3. 点击"确定"保存修改

### 4. 下载文件
1. 单个下载：点击文件操作菜单中的"下载"
2. 批量下载：选择多个文件，点击"下载"按钮

### 5. 删除文件
1. 单个删除：点击文件操作菜单中的"删除"
2. 批量删除：选择多个文件，点击"删除"按钮

## 重要说明

1. 文件上传后会同时保存到腾讯云COS和本地数据库
2. 删除文件时会同时删除COS存储中的文件
3. 大文件上传可能需要较长时间，请耐心等待
4. 建议使用现代浏览器以获得最佳体验
5. 视频文件支持在线预览，其他文件类型显示对应图标
6. 文件大小限制为1GB，超过限制的文件无法上传
